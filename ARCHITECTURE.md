# Architecture — Deep Modules & Seams

AgentGate is organized around **deep modules** placed at explicit **seams** (`typing.Protocol` in Python, Zod schemas + pure catalog-backed handlers in TypeScript) so core security, idempotency, and evaluation rules run in-process in milliseconds without AWS, Docker, or live LLM calls while keeping cloud, transport, and LLM adapters swappable.

## Security & Untrusted-Input Invariants

1. **Constant-Time Authentication Before Replay Checks:** `ingest_webhook()` verifies the HMAC-SHA256 signature (`v2=` over `{timestamp}.{idempotency_key}.{raw_body}`, or opt-in `v1=` over `{timestamp}.{raw_body}` when `allow_legacy_v1=True`) using `hmac.compare_digest` *before* evaluating the timestamp replay window so unauthenticated callers cannot probe server clock skew.
2. **Header Integrity & Bounded Payloads:** `WebhookIngress` rejects payloads exceeding `max_body_bytes` (`HTTP 413`), rejects duplicate or comma-folded `X-AgentGate-*` security headers (`HTTP 400`), and requires non-empty `X-AgentGate-Idempotency-Key`, `X-AgentGate-Signature`, and non-negative integer `X-AgentGate-Timestamp`.
3. **Atomic Idempotency & Failure Rollback:** `IdempotencyStore.claim()` runs atomically after authentication and replay validation so retries return `duplicate` (`HTTP 200`) without re-invoking triage. If downstream `triage_runner` execution fails, `WebhookIngress` calls `IdempotencyStore.release(event.idempotency_key)` and returns `HTTP 503` so legitimate retries can recover instead of being permanently locked out.
4. **Read-Only Tool Boundary & Prompt-Injection Guard:** MCP diagnostic tools enforce strict Zod parameter bounds (`maxLength`, `regex`, `enum`, `min`/`max`), sanitize ASCII control characters out of log lines, tag log responses `untrustedTelemetry: true`, and never expose write/exec primitives. `DeterministicJudge` and `detect_injection_compliance` fail any run that complies with untrusted `severity=` or `runbook=` directives.

## Locked Architecture Decisions

1. **Operations Console UI stack:** Next.js 15 App Router + React 19 + Tailwind CSS v4 in `packages/dashboard/`, consuming `sync-reports.mjs`-synced `src/data/{scenarios,latest-report,gemini-report,mcp-catalog}.json` and serving live `/api/triage` and `/api/triage/reset` endpoints with signed `HttpOnly` cookie session ledgers (`agentgate_demo_keys`).
2. **Primary persistence store:** Local SQLite (`WAL` mode + `BEGIN IMMEDIATE` in `SqliteIdempotencyStore`) and AWS DynamoDB conditional `PutItem` / `DeleteItem` (`DynamoDbIdempotencyStore`), both implementing `IdempotencyStore.claim()` and `.release()`.
3. **Live LLM adapter (`ToolRunner`):** Google Gemini `v1beta` REST (`GeminiToolRunner`, default `gemini-3.1-flash-lite`) with shared `RequestPacer` slot reservation across baseline and tool runners, `Retry-After` / exponential backoff for `429`/`5xx`, and recursive `sanitize_gemini_schema()` stripping Draft-07 keywords unsupported by Gemini `functionDeclarations`.
4. **Trace & eval observability (`TraceSink`):** Local OpenTelemetry-shaped JSONL (`JsonlOtelTraceSink`) by default plus optional Langfuse `/api/public/ingestion` batching (`LangfuseTraceSink`) wired together via `CompositeTraceSink`.
5. **AWS deployment target:** Serverless AWS SAM (`infra/template.yaml`: HTTP API + Python 3.11 `x86_64` Lambda + DynamoDB table with least-privilege `dynamodb:PutItem` / `dynamodb:DeleteItem` IAM and no S3 bucket), alongside `infra/Dockerfile` serving FastAPI + Uvicorn on port `8000`.
